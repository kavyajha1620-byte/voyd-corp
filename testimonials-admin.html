This page is where submissions land before they are public. It needs the studio's admin token to reach the server. The token is sent as a bearer credential and is never stored anywhere except this browser tab's session storage.

The server compares the token in constant time. If it is wrong you get a plain refusal and nothing else. If administration is not configured on the deployment, you will be told that instead.
